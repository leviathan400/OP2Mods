# Zoom-level reference screenshots

Drop the PNGs you pasted in chat here (the tooling can't save inline-pasted images to disk).
Suggested names, matching the three engine zoom levels (lower = wider):

- `zoom_in.png`   - most magnified, fewest tiles (engine `zoom = 3`).
- `zoom_mid.png`  - middle (engine `zoom = 2`).
- `zoom_wide.png` - current widest, what we play on (engine `zoom = 1`).

The new **"zoom 4"** we're adding should show **more map than `zoom_wide.png`**.
